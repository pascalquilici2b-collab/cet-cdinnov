# CDInnov — validation des évolutions

À la demande de l’utilisateur le 30 octobre 2026, les prochaines évolutions fonctionnelles de l’application doivent être vérifiées avec plusieurs agents, en testant le parcours utilisateur complet en local avant publication. Répartir l’implémentation, la revue des données et les tests d’interface ; conserver les liens entre clients, devis, factures, marchés et engagements.

Pour les tests, utiliser des données fictives et des services locaux. Ne pas envoyer d’e-mails ni créer de documents métier de production pour simuler un parcours. Distinguer les tests ciblés des anciens tests obsolètes dans les comptes rendus.
