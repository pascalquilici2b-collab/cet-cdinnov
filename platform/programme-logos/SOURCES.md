# Sources des logos de programme

Téléchargés le 23 octobre 2026 depuis les sites officiels, sans modification des visuels. Affichage proportionnel sur fond blanc dans les menus.

- Maritime : [site du programme](https://interreg-marittimo.eu/fr/comunicazione), [image](https://interreg-marittimo.eu/o/interreg-theme/images/logo-interreg.png).
- Euro-MED : [kit média](https://interreg-euro-med.eu/en/mediakit/), [image](https://interreg-euro-med.eu/wp-content/uploads/documents/logo-interreg-euro-med_web-1.png).
- NEXT MED : [site du programme](https://www.interregnextmed.eu/), [image](https://www.interregnextmed.eu/wp-content/uploads/2020/11/logo-colore.svg).
- Horizon Europe : emblème officiel de l’Union européenne, issu du [kit européen SVG en couleurs](https://european-union.europa.eu/principles-countries-history/symbols/european-flag_en). Il accompagne le nom dans la sélection interne de programme.
